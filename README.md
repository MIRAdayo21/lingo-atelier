# Lingo Atelier — 英語・韓国語の学習Webアプリ

英語の文法整理と韓国語の文法・短文読解を学習する、スマートフォン・PC対応の静的Webアプリ（PWA）です。

## 収録教材
- 英語：178枚 — 時制、完了形、語順、疑問文、前置詞、SNS・日常会話の表現
- 韓国語：158枚 — 助詞、文法、活用、短文読解、日常会話の表現
- フラッシュカード、4択、タイピング、復習管理、単語追加、学習統計、JSONバックアップ

## 公開方法（GitHub Pages）
1. このリポジトリの **Settings → Pages** を開く
2. **Build and deployment → Source → Deploy from a branch**
3. **Branch: main**、**Folder: /(root)** を選んで **Save**
4. デプロイ完了後に https://miradayo21.github.io/lingo-atelier/ へアクセス

## iPhone
Safariで上記のURLを開く。ホーム画面にアプリを追加するときは **共有 → ホーム画面に追加**。

## 保存について
- 学習記録はブラウザの localStorage に保存。サーバーには送信しません。
- iPhone・PC間で学習記録は自動同期されません。
- サイトデータ削除や別ブラウザへの変更に備え、必要なら設定からJSONバックアップしてください。
- オフライン利用は、公開サイトをオンラインで一度開いてキャッシュしたあとに利用できます。
- 発音読み上げは端末・ブラウザが提供する音声エンジンに依存します。
- 発音採点やAIとの自由会話、クラウド同期は未実装です。
